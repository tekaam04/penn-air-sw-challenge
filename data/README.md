# Input media

The challenge files are not committed (they are ~150 MB and belong to PennAiR).
Download them from the links in the challenge brief and drop them here with
these names:

| file | source |
| --- | --- |
| `static.png` | PennAir 2024 App Static.png |
| `dynamic.mp4` | PennAir 2024 App Dynamic.mp4 |
| `dynamic_hard.mp4` | PennAir 2024 App Dynamic Hard.mp4 |

Every command in the top-level README assumes those three names.
